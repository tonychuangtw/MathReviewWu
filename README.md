# MathReviewWu — 國中數學總複習重點整理

7-9 年級（六冊）數學總複習網站，內容轉錄自吳老師家教講義（63 單元、116 頁），供家教課系統化使用：老師依單元教學、標記進度，學生做筆記、練例題。

純靜態單頁應用：vanilla HTML/CSS/JS、無 build step、KaTeX 本地排版數學式、資料存 localStorage、Google 登入跨裝置同步（共用 LanExamMock 後端，app=mathwu）。

## 功能

- **六冊 63 單元**：照講義目次編排，每單元拆成觀念卡（講義填空處答案以紅字底線標示）
- **觀念卡**：重點整理 ＋ 精準 SVG 數學圖形 ＋ 原創例題（步驟詳解，點開對答案）
- **筆記區**：每張觀念卡下方有筆記欄（橫線稿紙樣式），輸入自動儲存；登入後跨裝置同步——學生寫的筆記老師手機直接看得到
- **教學進度標記**：每單元可標「已教過／需加強／已精熟」，首頁色條與 📊 進度總覽一目了然，家教課直接照表排進度
- **列印友善**：單元頁直接列印＝紙本講義（解答自動展開、介面元素隱藏）

## 開發

- 改資料：`js/data/units.js`（schema 見檔頭註解；轉錄原則：講義內容忠實轉錄、例題原創）
- 圖形：`node tools/gen-figs.js` 重生 `img/figs/*.svg`（程式計算座標，不手刻）
- 測試：`node test/test.js`（單元盤點、欄位完整性、KaTeX 定界符、圖檔存在）
- 部署：push main 即上 GitHub Pages

原始講義照片不入 repo（見 .gitignore），存本機 `photos/`。
